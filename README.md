# Feature Flag & Dynamic Config Manager

Lab work for the Software Engineering course, Dept. of CSE, PES University.

Gnanasagar H, PES1UG24CS171, Section 5 - 'C'

**Problem Statement #43:** A centralized configuration and feature toggling platform that supports
percentage-based user cohort rollouts, environment overrides, and real-time client SDK flag
synchronization. The labs build on this same system.

## Labs

| Lab | Topic | Deliverables |
|---|---|---|
| [Lab 1](Lab-1/) | Requirements Engineering & UML Use-Case Modelling | Requirements table, use-case diagram, use-case flow specification |
| [Lab 2](Lab-2/) | Agile Backlog Creation & Sprint Simulation in Jira | Epics and user stories, sprint board and burndown screenshots, sprint reflection |
| [Lab 3](Lab-3/) | Component Modelling & Architectural Pattern Selection | UML component diagram, written architectural justification |
| [Lab 4](Lab-4/) | Vibe Coding | Fixed and extended reaction time tester, before/after videos, chat history |

Further labs will be added here as the course progresses.

## Layout

Each lab lives in its own top-level folder with a short README describing its deliverables.
Diagrams are committed both as an exported PDF and as the editable draw.io source. Write-ups are
committed as Markdown, or as PDF where the lab asks for a document.

Course-supplied handouts and problem statements are not tracked.
